# 知识目录 / Knowledge Layout

以下展开现有逻辑目录及已确认子目录，作为可公开复用的结构契约。私有文件名、插件目录、内部账本及运行数据不属于此模板。\
The tree expands the established logical directories and verified subdirectories as a reusable structural contract. Private filenames, plugin directories, internal ledgers, and runtime material are outside the template.
