# Architecture

## One vault, two owners

```text
Human ──read/write──▶ 00_Human/   ◀──read-only── Agent
Agent ──maintain────▶ 10_Agent/wiki/ ◀──read/write── Human
Both  ──coordinate──▶ 20_Exchange/
Human ──govern──────▶ 30_System/   ◀──read-only── Agent
```

- `00_Human/`: PARA + MOC + Zettelkasten-friendly human knowledge.
- `10_Agent/raw/`: immutable sources (`documents`, `papers`, `websites`).
- `10_Agent/wiki/`: concepts, entities, topics, comparisons, synthesis, projects, decisions.
- `20_Exchange/`: tasks, proposals, handoffs, write requests, locks.
- `30_System/`: policies, schema, templates, workflows, reports.
- `90_Archive/`: retired content, never deleted.

## LLM Wiki layers

| Layer | Implementation |
| --- | --- |
| Raw sources | `10_Agent/raw/**` + `type: source` provenance pages |
| Wiki pages | `10_Agent/wiki/<type>/*.md`, YAML frontmatter, wikilinks |
| Schema | `30_System/schemas/agent-wiki.md` + `frontmatter.schema.json` |
| Index | `10_Agent/wiki/index.md`, managed block generated by `knowledgeos index` |
| Log | `10_Agent/wiki/log.md`, append-only |
| Ingest / Query / Update / Synthesize / Lint | `30_System/workflows/**`, exposed as CLI commands |

## Python engine

| Module | Responsibility |
| --- | --- |
| `config.py` | vault discovery, TOML config, paths, agent id |
| `paths.py` | canonicalization, traversal/symlink checks, atomic writes, backups, locks |
| `policy.py` | ownership matrix, actor/action decisions, write-request validation |
| `schema.py` | frontmatter parse/render, JSON Schema subset, note validation |
| `search.py` | keyword scoring, snippets, link index |
| `ingest.py` | raw copy + source record |
| `update.py` | create note, frontmatter/section/replace updates |
| `synthesize.py` | synthesis scaffold + source ledger |
| `index.py` | managed index block |
| `log.py` | append-only audit entries |
| `lint.py` | links, schema, index, duplicates, freshness, approvals |
| `installer.py` | new/incremental vault installation |
| `diagnostics.py` | `doctor` / `status` |
| `cli.py` | argparse surface, exit codes, JSON output |

No MCP server in v0.1. The Skill invokes the CLI, so any agent with shell access can use the same engine.

## Data flow for a write

```text
CLI args
  → Vault.resolve (normalize, reject traversal/symlink/protected)
  → policy.evaluate (region × actor × action, write request if human)
  → schema validation (agent areas)
  → atomic write + backup of the previous version
  → log append
  → index rebuild (wiki only)
```

## Non-goals

- AI memory, session capture, persona/profile storage.
- Automatic ingestion of every conversation.
- Semantic/vector search in v0.1.
- OS-level sandboxing.
- A plugin marketplace or Obsidian plugin.

## Extension points

- Add a new note type: schema + template + `TYPE_DIRS` + tests.
- Add a search backend: keep `search.search()` signature, return `SearchHit`.
- Add MCP later: wrap the existing Python functions; do not reimplement file logic.
