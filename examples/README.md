# Everyday workflows

Ask the agent to find overlapping notes, integrate a new source into an existing Agent note, or prepare a Human note proposal. For an existing real vault, use approved native file editing and its leases, backups, index, and log policy.

Use knowledgeos --vault VAULT doctor to inspect the readable scope. Use knowledgeos --vault VAULT ingest to render a source page draft, or synthesize to combine distinct readable inputs into a scaffold. Run either command with --help for argument order. An explicit --apply enables writing only in an approved test root outside the protected vault.
