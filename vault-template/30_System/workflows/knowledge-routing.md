# 知识工作流 / Knowledge Workflow

先查导航、标题、别名及来源，定位现有相关页面。
Start with indexes, titles, aliases, and provenance to find existing relevant notes.

摄取时保留原件及来源，综合时区分证据、推断及未决冲突。优先更新可复用页面，必要时建立关联明确的新页。
Preserve originals and provenance during intake. Distinguish evidence, inference, and unresolved conflicts during synthesis. Prefer updating a reusable note and create a new, clearly linked page when needed.

修改获准的 Agent 文件前确认范围及基线，写后检查引用、[索引](../../10_Agent/wiki/index.md)与[日志](../../10_Agent/wiki/log.md)。Human 变更交付[提案](../templates/human-change-proposal.md)。
Confirm the scope and baseline before editing an approved Agent file. Verify references, the [index](../../10_Agent/wiki/index.md), and the [log](../../10_Agent/wiki/log.md) afterward. Deliver [proposals](../templates/human-change-proposal.md) for Human changes.
