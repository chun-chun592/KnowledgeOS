# Human 知识变更提案 / Human Note Change Proposal

- 目标相对路径 / Target relative path
- 基础 SHA-256 / Base SHA-256
- 修改理由及原文上下文 / Rationale and original context
- 完整建议 Markdown / Complete proposed Markdown
- 统一 diff / Unified diff
- 来源与相关知识引用 / Sources and related knowledge

由 Human 使用任意编辑器审核及应用。提案本身不写入目标文件。
The Human reviews and applies the proposal in any editor. Creating a proposal leaves the target file untouched.
