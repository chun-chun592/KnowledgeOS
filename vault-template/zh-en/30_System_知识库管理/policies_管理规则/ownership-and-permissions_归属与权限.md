# Ownership and Permissions

Humans can maintain their knowledge with any editor. Agents read and cite only within the actual task authorization, and write only to explicitly approved Agent paths.

In the existing real vault, MCP and CLI stay read-only. Approved native edits follow the vault's lease, backup, base SHA-256, post-write verification, and targeted index and log rules.

Deliver Human changes as proposals. These are application-level rules; Strict Mode is configured separately.

# 知识归属与权限

Human 可以用任意编辑器维护自己的知识。Agent 根据当前任务的实际授权读取及引用相应内容，只能在明确授权的 Agent 路径内写入。

在现有真实库，MCP 和 CLI 保持只读。获准原生编辑遵循该库的租约、备份、基础 SHA-256、提交复核和索引／日志定点同步规则。

Human 文件修改以提案交付。规则属于应用层治理，Strict Mode 另行配置。
