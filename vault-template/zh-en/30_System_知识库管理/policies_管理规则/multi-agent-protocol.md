# 多 Agent 协作

受保护变更及索引或日志写入前取得现有租约。保留创建者标识，记录实质贡献和写入。公共新增只增加对应条目和事件。用自动反链建立回链，并在协作区处理租约冲突。
# Collaboration

Acquire existing leases before protected changes and index or log edits. Keep the creator ID, append meaningful contributions and log writes. Shared creation can add only the new row and event. Use existing computed backlinks. Coordinate conflicting leases through Exchange.
