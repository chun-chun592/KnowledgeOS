# 知识工作入口

沿用原有私有知识分类，并使用独立公共区。按任务选择技能与工具。先查重，按用途和出处授权选择区域，保留来源和关联。执行前查看[归属与审批规则](../policies_管理规则/ownership-and-permissions_归属与权限.md)。
# Knowledge workflow

Use the existing private classifications and the new Shared region. Select Skills and tools by task. Search before writing, choose the destination by audience and source permissions, and preserve citations. Consult the [ownership and execution rules](../policies_管理规则/ownership-and-permissions_归属与权限.md).
