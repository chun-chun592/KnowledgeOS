# Human Knowledge Index

Use this page to organize active projects, ongoing areas, resource topics, and maps of content.

# 人类知识导航

在此整理活跃项目、长期领域、资源主题与知识地图。

## Organize personal knowledge

Inbox_收件箱 holds uncategorized material, Daily_日常笔记 holds dated notes, Projects_项目 holds time-bounded work, and Areas_长期领域 tracks ongoing responsibilities. Resources_知识资源 holds concept, reading, permanent and reference notes. Use MOCs_知识地图 for topic maps, Attachments_附件 for media, book_书籍 for book material, Clippings_剪藏 for excerpts, and Archive_归档 for inactive material.

## 组织个人知识

收件箱收集待处理资料，日常笔记按日期记录，项目组织有明确目标的工作，长期领域管理持续责任。知识资源包含概念笔记、阅读笔记、永久笔记和参考资料。用知识地图串联主题，附件存放媒体，书籍整理读书资料，剪藏保留片段，归档存放暂不活跃的内容。
