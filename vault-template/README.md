# Optional test vault template

Set KNOWLEDGEOS_PROTECTED_VAULT to the existing protected root. Create an empty separate directory and run knowledgeos --vault TEST_ROOT init. This creates the standard subdirectories, including the shared lease directory, without changing the existing vault.
